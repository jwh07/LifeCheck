# LifeCheck - 생활용품 사용 기간 관리 프로그램

> **심화프로그래밍 팀 프로젝트**  
> 팀 구성: 총 3명 | 개발 언어: Python (tkinter) | 데이터 저장: CSV

---

## 1. 프로젝트 개요
`LifeCheck`는 일상생활에서 사용하는 생활용품(화장품, 세정용품, 위생용품 등)의 개봉일과 사용 가능 기간을 등록하고 관리하는 Windows 데스크톱 프로그램입니다.  
별도의 인터넷 연결이나 복잡한 데이터베이스 설치 없이 실행할 수 있으며, 현재 날짜를 기준으로 남은 기간과 교체 시기(사용 가능, 기간 임박, 기간 만료)를 자동으로 계산하여 시각적으로 보여줍니다.

---

## 2. 주요 기능
1. **생활용품 등록 및 관리 (CRUD)**
   - 제품명, 분류, 개봉일(`YYYY-MM-DD`), 사용 가능 기간(개월) 입력
   - 등록(`Add`), 조회(`Read`), 수정(`Update`), 삭제(`Delete`) 지원
   - 오늘 날짜 자동 입력 버튼 제공
2. **사용 기간 자동 계산 (`datetime`)**
   - 개봉일과 사용 개월 수를 바탕으로 **사용 가능 종료일 자동 계산** (윤년 및 말일 자동 보정)
   - 오늘 날짜 기준 **남은 일수(D-Day)** 실시간 계산
3. **상태 자동 판정 및 시각화**
   - **사용 가능:** 남은 일수 31일 이상 (초록색 텍스트)
   - **⚠️ 기간 임박:** 남은 일수 0일 ~ 30일 (주황색 강조)
   - **🚨 기간 만료:** 사용 종료일 경과 (빨간색 강조)
4. **목록 필터링 및 현황 요약**
   - `전체 보기`, `기간 임박`, `기간 만료`, `사용 가능` 필터 라디오 버튼 제공
   - 등록된 총 제품 수 및 임박/만료 제품 개수 실시간 집계 요약
5. **안전한 데이터 보존 (CSV)**
   - 프로그램 재실행 시에도 데이터가 영구 보존됨 (`data/items.csv`)
   - `utf-8-sig` 인코딩 적용으로 엑셀(Excel)에서 열어도 한글 깨짐 없음
6. **예외 처리 및 유효성 검사**
   - 필수값 누락 경고창
   - 잘못된 날짜 형식(`YYYY-MM-DD` 외) 차단
   - 사용 기간 0 이하 또는 문자 입력 차단

## 3. 파일 구조 및 역할

```
LifeCheck/
│
├── main.py              # [팀원 1] GUI 화면 구성, 사용자 입력 및 버튼 이벤트 처리
├── storage.py           # [팀원 2] CSV 파일 입출력 및 데이터 관리(추가/수정/삭제)
├── calculator.py        # [팀원 3] datetime 날짜 연산, D-Day 계산, 상태 판정 로직
├── run.bat              # 더블 클릭으로 프로그램을 바로 실행하는 윈도우 배치 파일
├── README.md            # 프로젝트 안내 및 메뉴얼
└── data/
    └── items.csv        # 제품 정보가 저장되는 영구 CSV 데이터 파일
```

---

## 4. 실행 방법

### 방법 A. 간편 실행 (추천)
- 프로젝트 폴더의 **`run.bat`** 파일을 더블 클릭합니다.

### 방법 B. 터미널 실행
1. 터미널(PowerShell 또는 CMD)을 열고 프로젝트 폴더로 이동합니다.
2. 아래 명령어를 실행합니다:
   ```powershell
   python main.py
   # 또는
   py main.py
   ```

## 5. 팀원별 역할 분담

| 팀원 | 담당 역할 | 주요 기여 내용 |
| :---: | :--- | :--- |
| **팀원 1** | **GUI 및 이벤트 처리** (`main.py`) | - tkinter/ttk 기반의 2분할 윈도우 화면 설계<br>- 버튼 클릭 이벤트, 목록(Treeview) 클릭 시 입력창 자동 연동<br>- 실시간 필터 라디오 버튼 및 색상 태그(Highlight) 구현 |
| **팀원 2** | **데이터 영속성 관리** (`storage.py`) | - `csv` 내장 모듈을 이용한 데이터베이스 구현 (`items.csv`)<br>- 고유 ID 자동 채번 및 CRUD(등록, 조회, 수정, 삭제) 로직 작성<br>- `utf-8-sig` 인코딩 적용으로 Windows 한글 호환성 확보 |
| **팀원 3** | **비즈니스 로직 및 검증** (`calculator.py`) | - `datetime` 기반의 개월 수 가산 및 사용 종료일 계산 로직 구현<br>- 남은 일수(D-Day) 및 3단계 상태 판정 함수 작성<br>- 날짜 형식 검증 함수 및 비정상 입력값 단위 테스트 수행 |
