# LifeCheck - 생활용품 사용 기간 관리 프로그램

> **심화프로그래밍 팀 프로젝트**  
> 팀 구성: 총 3명 | 개발 언어: Python (tkinter) | 데이터 저장: CSV

---

## 1. 프로젝트 개요
`LifeCheck`는 일상생활에서 사용하는 생활용품(화장품, 세정용품, 위생용품 등)의 개봉일과 사용 가능 기간을 등록하고 관리하는 Windows 데스크톱 프로그램입니다.  
별도의 인터넷 연결이나 복잡한 데이터베이스 설치 없이 실행할 수 있으며, 현재 날짜를 기준으로 남은 기간과 교체 시기(사용 가능, 기간 임박, 기간 만료)를 자동으로 계산하여 시각적으로 보여줍니다.

---

## 2. 주요 기능
1. **생활용품 등록 및 관리 (CRUD)**
   - 제품명, 분류, 개봉일(`YYYY-MM-DD`), 사용 가능 기간(개월) 입력
   - 등록(`Add`), 조회(`Read`), 수정(`Update`), 삭제(`Delete`) 지원
   - 오늘 날짜 자동 입력 버튼 제공
2. **사용 기간 자동 계산 (`datetime`)**
   - 개봉일과 사용 개월 수를 바탕으로 **사용 가능 종료일 자동 계산** (윤년 및 말일 자동 보정)
   - 목록 갱신 시 오늘 날짜 기준 **남은 일수(D-Day)** 계산
   - 프로그램을 켜둔 채 날짜가 바뀌면 1분 이내 기준일과 목록 자동 갱신
3. **상태 자동 판정 및 시각화**
   - **사용 가능:** 남은 일수가 설정한 임박 기준보다 긴 경우 (초록색 텍스트)
   - **⚠️ 기간 임박:** 남은 일수 0일 ~ 설정한 임박 기준 (주황색 강조, 기본 30일)
   - **🚨 기간 만료:** 사용 종료일 경과 (빨간색 강조)
4. **목록 필터링 및 현황 요약**
   - `전체 보기`, `기간 임박`, `기간 만료`, `사용 가능` 필터 라디오 버튼 제공
   - 사용 중 제품 수, 임박/만료 제품 수, 사용 완료 이력 수 집계
5. **안전한 데이터 보존 (CSV)**
   - 프로그램 재실행 시에도 데이터가 영구 보존됨 (`data/items.csv`)
   - `utf-8-sig` 인코딩 적용으로 엑셀(Excel)에서 열어도 한글 깨짐 없음
6. **예외 처리 및 유효성 검사**
   - 필수값 누락 경고창
   - 잘못된 날짜 형식(`YYYY-MM-DD` 외) 차단
   - 사용 기간 0 이하 또는 문자 입력 차단
   - 사용 완료일의 잘못된 날짜·개봉일 이전 날짜·미래 날짜 차단
   - 저장 및 불러오기 오류 안내, 저장 중 실패 시 기존 파일 보존
7. **제품 검색 및 맞춤형 기간 알림 — 추가 기능 4**
   - 제품명 부분 검색(영문 대소문자 구분 없음), 분류별 조회, 상태 필터 동시 적용
   - `등록 순` 또는 `남은 기간순` 정렬 (남은 기간순은 만료 제품부터 표시)
   - 임박 기준을 **7일·14일·30일** 중 선택, 변경 즉시 목록과 요약에 반영
   - 설정은 `data/settings.json`에 저장되어 재실행 후에도 유지
   - 프로그램 실행 시 검색 조건에 관계없이 사용 중인 임박·만료 제품 안내
   - 프로그램 종료 상태에서의 알림은 제공하지 않음
8. **사용 완료 및 교체 이력 관리 — 추가 기능 5**
   - 제품 선택 → `사용 완료` → 완료일 입력으로 이력 보관
   - 상단 목록을 `사용 완료 이력`으로 변경하여 완료일과 제품 정보 확인
   - 완료 제품은 사용 중 목록, 임박·만료 집계, 실행 시 알림에서 제외
   - 이력에서 `같은 제품 다시 등록` → 새 개봉일·기간 확인 → `등록`
   - 기존 이력은 유지하고 새 ID의 사용 중 제품 생성 (이력 직접 수정은 제한, 삭제는 가능)

## 3. 파일 구조 및 역할

```
LifeCheck/
│
├── main.py              # [팀원 1] GUI 화면 구성, 사용자 입력 및 버튼 이벤트 처리
├── storage.py           # [팀원 2] CSV 파일 입출력 및 데이터 관리(추가/수정/삭제)
├── calculator.py        # [팀원 3] 날짜 계산, 상태 판정, 검색·정렬 및 알림 대상 계산
├── run.bat              # 더블 클릭으로 프로그램을 바로 실행하는 윈도우 배치 파일
├── README.md            # 프로젝트 안내 및 메뉴얼
├── data/
│   ├── items.csv        # 기존 제품 정보 + 완료 상태 및 완료일
│   └── settings.json    # 임박 기준 변경 시 자동 생성되는 사용자 설정
└── tests/
    └── test_lifecheck.py # 날짜·저장·추가 기능 및 실제 Tk GUI 동작 테스트
```

기존 `main.py`, `storage.py`, `calculator.py`의 구성을 유지하고 외부 패키지 없이 Python 표준 라이브러리만 사용합니다.

기존 6열 CSV는 파일을 즉시 변환하지 않고 모든 제품을 `사용중`으로 읽습니다. 제품 등록·수정·삭제·완료 처리로 저장할 때만 `usage_status`, `completed_date` 열을 추가하며 기존 제품 정보와 ID는 보존합니다. `settings.json`이 없거나 손상된 경우 임박 기준은 30일로 적용됩니다.

## 4. 실행 방법

### 방법 A. 간편 실행 (추천)
- 프로젝트 폴더의 **`run.bat`** 파일을 더블 클릭합니다.

### 방법 B. 터미널 실행
1. 터미널(PowerShell 또는 CMD)을 열고 프로젝트 폴더로 이동합니다.
2. 아래 명령어를 실행합니다:
   ```powershell
   python main.py
   # 또는
   py main.py
   ```

### 추가 기능 사용 순서
1. 우측 상단에서 `사용 중` 또는 `사용 완료 이력`을 선택합니다.
2. 제품명 검색어와 분류를 지정합니다. 사용 중 목록에서는 상태 필터와 정렬도 함께 적용할 수 있습니다.
3. `임박 기준`을 바꾸면 저장된 기준에 맞춰 상태가 다시 계산됩니다.
4. 사용 중 제품을 선택하고 `사용 완료`를 누르면 삭제 대신 이력으로 보관됩니다.
5. 이력에서 제품을 선택하고 `같은 제품 다시 등록`을 누르면 기존 정보가 입력됩니다. 새 개봉일을 확인하고 `등록`을 눌러 완료합니다.

조회 조건을 바꾸면 기존 제품 선택과 입력 내용은 초기화됩니다. 완료 이력에서는 기간 상태 필터와 남은 기간 정렬이 비활성화되고 최근 완료일 순으로 표시됩니다. 현황 요약은 검색 결과가 아닌 전체 사용 중 제품을 기준으로 집계합니다.

## 5. 팀원별 역할 분담

| 팀원 | 담당 역할 | 주요 기여 내용 |
| :---: | :--- | :--- |
| **팀원 1** | **GUI 및 이벤트 처리** (`main.py`) | - tkinter/ttk 기반의 2분할 윈도우 화면 설계<br>- 버튼 클릭 이벤트, 목록(Treeview) 클릭 시 입력창 자동 연동<br>- 실시간 필터 라디오 버튼 및 색상 태그(Highlight) 구현 |
| **팀원 2** | **데이터 영속성 관리** (`storage.py`) | - `csv` 내장 모듈을 이용한 데이터베이스 구현 (`items.csv`)<br>- 고유 ID 자동 채번 및 CRUD(등록, 조회, 수정, 삭제) 로직 작성<br>- `utf-8-sig` 인코딩 적용으로 Windows 한글 호환성 확보 |
| **팀원 3** | **계산·추가 기능·테스트** (`calculator.py`, 추가 기능 관련 변경, `tests/`) | - 날짜 연산, D-Day 및 임박 기준에 따른 상태 판정<br>- 추가 기능 4: 검색·정렬·맞춤 알림 및 설정 저장<br>- 추가 기능 5: 사용 완료·교체 이력 관리<br>- 추가 기능의 GUI 연동과 데이터 처리 포함<br>- 기존 CSV 호환성, 계산·저장 로직, GUI 흐름 테스트 |

추가 기능 4·5는 팀원 3(원태희)의 담당 범위입니다. 기존 파일의 역할을 유지하기 위해 해당 기능의 화면·이벤트 연동은 `main.py`, 데이터 처리는 `storage.py`, 검색·상태 계산은 `calculator.py`에 나누어 구현했습니다.

## 6. 테스트

프로젝트 폴더에서 실행합니다.

```powershell
python -m unittest discover -s tests -v
```

기존 CSV 읽기 및 저장 시 확장, CRUD, 월말·윤년 계산, 임박 기준의 경계값, 검색 조건 조합, 완료 이력 보존, 설정 재사용 및 저장 실패 시 원본 보존을 확인합니다. tkinter 실행이 가능한 환경에서는 실제 Tk 위젯으로 검색·완료 처리·다시 등록·수정·삭제·날짜 변경 흐름도 검사합니다. GUI를 실행할 수 없는 환경에서는 GUI 테스트만 건너뜁니다.

테스트 데이터는 테스트 폴더 내부의 임시 디렉터리에서 생성·정리하며 실제 `data/items.csv`와 설정은 변경하지 않습니다.
